Getting Started with CIMEHR

Introduction

Longitudinal analyses of Electronic Health Record (EHR) data face two sources of bias that are typically absent from designed studies:

  1. Informative visiting: patients visit more or less frequently depending on their health status and covariates, so the observation times are not independent of the outcome process.
  2. Informative observation: even at a visit, the biomarker or outcome may not be measured. Whether it is recorded can depend on the same latent factors that drive the outcome.

Ignoring either source produces biased estimates of longitudinal associations. CIMEHR provides the GIVEHR() family of estimators — three-stage semiparametric methods that jointly model both mechanisms — together with nine benchmark comparison methods for simulation studies.

This vignette walks through a complete analysis using the pre-generated example dataset sim_ehr_data (2000 subjects).

library(CIMEHR)

2. Covariate Flexibility

All functions in CIMEHR accept user-defined column names and covariate sets. The GIVEHR family uses character vectors to specify covariates:

# If your data has columns "patient_id", "age", "female", "visit_time",
# "hba1c", "measured", "followup_end":
GIVEHR(
  data     = my_data,
  id_col   = "patient_id",
  time_col = "visit_time",
  y_col    = "hba1c",
  r_col    = "measured",
  censor_col = "followup_end",
  covars_visit_XV         = c("age", "female"),
  covars_outcome_fixed_XY = c("age", "female"),
  covars_outcome_link_ZY  = "female",
  covars_obs_fixed_XO     = c("age", "female"),
  covars_obs_random_ZO    = "female"
)

The formula-based methods (Linear Mixed Model (LMM), Inverse Intensity Rate Ratio (IIRR), Pairwise Composite Likelihood (PCL)) use standard R formulas:

LMM(my_data,
    id    = "patient_id",
    fixed = hba1c ~ age + female + visit_time,
    random = ~ 1 | patient_id,
    obs_indicator = "measured")

3. The GIVEHR Family (Primary Methods)

3.1 GIVEHR

The core Generalized Informative Visiting and Electronic Health Record (GIVEHR) estimator uses three stages: (1) partial likelihood for the visiting process with a log-normal frailty; (2) probit regression for the observation process with latent-factor-linked random effects; and (3) weighted least squares (WLS) with risk-set centering for the longitudinal outcome. Sandwich variance estimators provide standard errors for all three stages.

fit_givehr <- GIVEHR(data = sim_ehr_data)

3.2 GIVEHR with Gauss–Hermite Quadrature (GIVEHR_GH)

GIVEHR_GH replaces the closed-form marginal approximation in Stage 2 with Gauss–Hermite (GH) quadrature and an online Laplace filter. This is more accurate when the frailty variance is large or when a time-varying observation process is needed.

Note: Standard errors are not currently available for GIVEHR_GH. Use GIVEHR() or bootstrap for inference.

fit_gh <- GIVEHR_GH(
  data        = sim_ehr_data,
  gh_points_U = 7,
  gh_points_q = 5
)

print(fit_gh)

4.8 Linear Increment Imputation with Informative Presence Adjustment (LI_IP)

A two-stage procedure: (1) impute missing outcomes using the Linear Increment (LI) model (Aalen and Gunnes, 2010), then (2) apply an Informative Presence (IP) adjustment method to the completed dataset.

Standard error availability depends on the downstream IP method chosen. Single imputation does not capture imputation uncertainty.

fit_li <- LI_IP(
  data       = sim_ehr_data,
  ip_method  = "LMM",
  visit_covs = c("Z", "X")
)
#> Stage 1: Linear Increment Imputation...
#>   LI model: Y ~ Z + X + time
#>   Covariance structure: randomwalk
#>   Imputed 18006 missing values
#> 
#> Stage 2: Applying LMM...
#> Done!
print(fit_li)
#>

4.9 Multiple Imputation with Informative Presence Adjustment (MI_IP)

A three-stage procedure: (1) multiply impute missing outcomes via mice, (2) apply an IP method to each completed dataset, and (3) pool results. Standard error availability depends on the downstream IP method.

fit_mi <- MI_IP(

  ip_method  = "LMM",

6. Uncertainty Quantification Summary

Not all methods provide standard errors. The table below summarises what is available:

Method Standard Errors Source
GIVEHR Yes (all stages) Sandwich variance
GIVEHR_GH No Use GIVEHR or bootstrap
GIVEHR_OU_PCL Yes (outcome) Sandwich variance
EHRJoint No Bootstrap
JMVL_Liang No Bootstrap
IIRR_weighting No Bootstrap
IIRR_balancing No Bootstrap
LMM Yes Model-based (nlme)
SummaryStat Yes Model-based (lm)
PairwiseLikelihood Yes (naive) Inverse Hessian
LI_IP Depends on IP method Passes through; no imputation uncertainty
MI_IP Depends on IP method Rubin’s rules when SE available
